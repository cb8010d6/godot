# 增量证据整理方法

这是供审阅的独立增量实测证据记录。整理过程没有运行 GPU、引擎、导入或构建。旧 50 文件审计稿与其 manifest 保持不变；新增数据只从已经结束的真实回执收集。

- `evidence/` 保留完整选定 JSON，仅机器路径/账户标识字符串及对应 key 脱敏为逻辑标识。字段/数组结构、数字、布尔值、null 和 verdict 不变。
- `logs/` 保留所有原行，只替换机器路径；ERROR、shader error、VUID、编译错误和警告计数不变。
- `images/` 保留原 PNG 字节。BCC 前图来自 helper 前端失败，A028 后图是部分修复；A738 后图来自独立完成的最终六例指定机位。[报告](REPORT.md) 分开说明自动断言、目视失败、冷异步灰早图和小夹具验证范围。
- [MANIFEST.json](MANIFEST.json) 记录原始/公开字节数、SHA-256 和逻辑来源；报告和说明是整理分析，不是 native 回执。manifest 自身哈希由工具另报。

发布前应复核最终范围和完整回执，并验证 Git 暂存 blob 精确字节与 manifest 一致（避免换行转换）。不得提交旁边含本机路径的工具或失败整理目录，不得覆盖既有冻结验收包。自动 PASS 不取代图像验收；保守排除的材质路径和未执行项目不能写作支持或通过。
